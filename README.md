# 国际赛事志愿服务时段与奖励

编排国际赛事志愿者的资质、班次、替班、签到与表彰。

## 参与方与事实

主要参与方包括赛事服务中心、志愿者、岗位负责人、外语协调员、表彰审核人员。领域资料记录以下已经确认的事实：

- 世赛志愿者承担媒体酒店、制证、机场和告别活动保障
- 志愿者服务跨越清晨到深夜且有长期管理岗位
- 小语种志愿者负责外籍团队接待和沟通

## 业务约束

- 休息间隔
- 语言资质
- 班次互斥
- 替班审批
- 服务时长

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/volunteer_context.py` 负责读取和校验这些资料。

`src/roster.py` 在同一条只增事件链上实现排班、替班、签到、交接与表彰：

- 排班同时校验休息间隔（默认 10 小时）、岗位培训资质、班次互斥、场地人数与服务对象语言；`validate_shift_ready` 做班前就绪检查。
- 签到/签退不可回写；已开始的班次只能追加异常与交接。
- 替班必须原负责人与主管分别确认，主管不能是当事人；生效后服务时长归实际服务者。
- 单班临时取消只释放本班名额；恢复时从事件日志重放，续办未审核替班与即将开始的班次。
- 表彰禁止自批，且对每段服务给出计入/排除原因与证据事件序号。

规则细节见 `docs/domain-rules.md`，可执行示例见 `tests/test_roster.py`。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
