# 领域边界

编排国际赛事志愿者的资质、班次、替班、签到与表彰。

现有领域资料围绕以下边界组织：

- 志愿者与岗位资质
- 班次需求与排班
- 签到与交接
- 替班审批
- 时长与表彰

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 已确认规则

`src/roster.py` 在同一条记录链上落实以下规则：

1. 排班同时校验休息间隔、岗位资质、场地人数和服务对象语言；同一志愿者不能重复排班，也不能承接时间冲突的班次。
2. 班次开始后签到事实冻结，只能追加异常和交接。
3. 替班申请须原负责人与主管分别确认，主管确认须独立于替班双方；双方确认时若替班人已不再满足排班约束，申请被拒绝并在记录链上留痕。
4. 临时替班不删除原负责人的签到与服务记录，替班人的服务时长照常计入表彰依据。
5. 任何人不能批准自己的奖励，表彰须由登记的表彰审核人员批准。
6. 机场接送或酒店安排临时取消时，只取消相关班次并释放相关名额，其他岗位保持不变。
7. 系统恢复后重放记录链，继续处理未审核的替班和即将开始的班次。
8. 每份表彰都能说明每段服务被包含或排除的原因：缺少签到记录、班次已取消、名额已释放、已由他人替班、班次尚未完成、不在表彰周期内。
