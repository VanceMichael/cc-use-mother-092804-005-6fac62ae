# 领域边界

编排国际赛事志愿者的资质、班次、替班、签到与表彰。

现有领域资料围绕以下边界组织：

- 志愿者与岗位资质
- 班次需求与排班
- 签到与交接
- 替班审批
- 时长与表彰

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 记录链

报名、语言能力、岗位培训、班次需求、签到、替班、异常、交接与奖励落在同一条
只增事件链上（`src/roster.py`）：

- 每个命令产生带序号的事件，状态由重放得到；系统恢复后用 `Roster.from_events`
  重建，继续处理 `pending_substitutions()` 与 `upcoming_shifts()`。
- 签到/签退是事实：重复签到、回写、早于签到的签退一律拒绝。
- 班次开始后只接受 `add_exception` 与 `record_handover`，不能改派名额、
  释放名额或整体取消。

## 排班约束

- 休息间隔：默认相邻班次至少间隔 10 小时（`REST_INTERVAL`）。
- 岗位资质：必须持有该岗位的培训合格记录。
- 班次互斥：同一志愿者时间重叠的班次不能重复排班。
- 场地人数：在岗人数不得超过需求名额；排班语言校验按"剩余名额能否补齐
  缺失语种"判断，班前用 `validate_shift_ready` 确认人数到齐、语言全覆盖。
- 班前言愿释放名额时，同样校验释放后语种仍可补齐。

## 替班与奖励

- 替班申请先由原负责人本人确认，再由非当事人主管审批；顺序不能颠倒。
- 替班人独立满足资质、语言、休息规则；替班生效后名额换人，
  后续签到记在替班人身上，原负责人该段服务在表彰中标记"替班已转出"。
- 机场接送、酒店安排等临时取消只释放该班次名额（`cancel_requirement`），
  其他班次不动。
- 任何人不能批准自己的奖励，且审批人须有表彰权限。
- `service_periods` 与 `award_explanation` 对每段服务给出计入/排除原因
  及证据事件序号（含异常、交接），可回答一段表彰为何包含或排除某段服务。
